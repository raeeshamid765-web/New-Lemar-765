NEW LEMAR V5.2.1 on iPhone - how to REPLACE your old app (data stays)
=====================================================================
IMPORTANT: keep the SAME web address (same GitHub repository). Your data belongs to that address.

BEFORE ANYTHING (safety)
1. Open the OLD app on the iPhone > Settings > Backup > choose "Save to Files" > press "Yes, I saved it" only after it is really saved.

REPLACE THE FILES ON GITHUB (from the website, no programming)
1. Sign in to github.com and open your existing repository (the one that holds the old app).
2. Click the file  index.html  > pencil/trash icon: easiest is: click "Add file" > "Upload files".
3. Drag these 6 files from this folder:  index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png
   (files with the same name are replaced). Click "Commit changes".
4. Wait 1-2 minutes (Settings > Pages shows "Your site is live").

UPDATE ON THE IPHONE
1. Connect to the internet. Open the app from the home-screen icon. Close it completely (swipe it away).
2. Open it again. The title must say "V5.2.1" (the update appears on the 2nd open). If not, repeat once more.
3. Old data: V5 should pick up your old data automatically the first time (not tested with real V4 data). Check customers, invoices, inventory, workers.
   If anything is missing: Settings > Restore backup > pick the backup file you saved above.
4. Make a new Backup (Save to Files) right after checking.
Never delete the home-screen icon and never change the web address.
